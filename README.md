# Shubh Deepawali — Anuratna Khare

A responsive, single-page Diwali greeting website with animated fireworks, a night sky, glowing diyas, an Indian-inspired skyline/temple silhouette, and tap-to-celebrate interactions.

## Publish on GitHub Pages
1. Create a new GitHub repository (or open your existing website repository).
2. Upload `index.html` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site; open the URL shown in the Pages section.

The page is self-contained. It uses Google Fonts when internet access is available; the rest of the design and animations are built into the HTML file.
